For developers

The Walang Pasok API

Plain JSON files, rebuilt every time the news is checked. No key, no sign-up. Fetch them from a Discord bot, a school website or a spreadsheet.

Is there class today?

GET {{ site_url }}/api/v1/check/{{ example }}.json
GET {{ site_url }}/api/v1/check/{{ example }}/tomorrow.json

suspended is true or false. details lists each verified suspension that covers the place, including ones declared for its province or region, and sources links to the proof. Find a place's slug in locations.json.

All files

FileWhat it holds
/api/v1/check/<slug>.jsonToday ({{ today | longdate }}, Asia/Manila) for one city or municipality
/api/v1/check/<slug>/tomorrow.jsonTomorrow for one place
/api/v1/suspensions/today.jsonToday's verified suspensions nationwide
/api/v1/suspensions.jsonThe latest 100 verified suspensions, newest first
/api/v1/locations.jsonEvery region, province, city and municipality (PSGC), with slugs

Example

curl {{ site_url }}/api/v1/check/{{ example }}.json

// JavaScript
const r = await fetch("{{ site_url }}/api/v1/check/{{ example }}.json");
const { suspended, details } = await r.json();
